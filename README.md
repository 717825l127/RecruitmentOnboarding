1. Problem Statement

Design and develop a Java console-based Recruitment & Onboarding System to manage the recruitment process, including job postings, applicants, applications, interviews, job offers, onboarding tasks, and employee records.

The application uses object-oriented programming principles, input validation, encapsulation, and candidate status management. It provides a menu-driven console interface that allows users to perform recruitment and onboarding operations efficiently.

2. Objectives

* Manage job postings and applicant information.
* Register applicants and process job applications.
* Schedule interviews and record interview results.
* Issue job offers to eligible candidates.
* Accept or reject job offers.
* Create and manage onboarding tasks.
* Track onboarding task completion.
* Convert eligible candidates into employees.
* Validate user inputs and enforce business rules.
* Maintain consistent candidate statuses throughout the recruitment lifecycle.

3. Features

1. Job posting management.
2. Applicant registration and management.
3. Job application processing.
4. Interview scheduling and result management.
5. Job offer creation and management.
6. Offer acceptance and rejection.
7. Onboarding task creation and tracking.
8. Employee record management.
9. Input validation and error handling.
10. Menu-driven console interface.

4. Classes Used

* JobPosting: Stores and manages job posting details.
* Applicant: Stores applicant information.
* Application: Manages job applications and their statuses.
* Interview: Manages interview details and results.
* Offer: Manages job offers and acceptance or rejection.
* OnboardingTask: Tracks onboarding activities and completion.
* Employee: Stores employee details after successful recruitment.

The project also contains a main class responsible for launching the application and displaying the console menu.

5. Business Rules

1. Every application must be associated with a valid job posting and applicant.
2. Interviews can be scheduled only for eligible applications.
3. Job offers can be issued only after successful interviews.
4. Candidates can accept or reject job offers.
5. Onboarding tasks are created after an offer is accepted.
6. Employee creation must follow the conditions defined by the application.
7. Candidate statuses must follow valid transitions.
8. Invalid inputs and unsupported operations must be handled appropriately.
9. Class attributes should follow encapsulation principles.

8. How to Import the Project into Eclipse

1. Open Eclipse IDE.
2. Select File → Import.
3. Choose General → Existing Projects into Workspace.
4. Click Next.
5. Browse to the folder containing the project.
6. Select the project and click Finish.

If the project is already open in Eclipse, skip these steps.

9. How to Compile and Run in Eclipse

Step 1: Open the Project

Open the project in Eclipse and locate the main Java class containing the main() method.

Step 2: Check the Source Files

Step 3: Run the Application
